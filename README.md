# SecondHandParts mobile app

A React Native (Expo) mobile experience for browsing and ordering second-hand vehicle parts with simple search, filtering, and cart management.

## Features
- Browse curated listings with images, pricing, and condition tags.
- Search by part name or vehicle and filter by category.
- View rich detail pages with seller trust signals.
- Add items to a cart and track totals.

## Getting started
1. Install dependencies (requires Node.js):
   ```bash
   npm install
   ```
2. Start the Expo development server:
   ```bash
   npm start
   ```
3. Open the app on iOS, Android, or web via Expo prompts.

The UI uses mock data in `src/data/sampleParts.ts` so it runs without a backend.
